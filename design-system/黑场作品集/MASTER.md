# 黑场作品集设计系统

## 2026-10-19 首页定稿覆盖

用户选定白底版本，首页首屏覆盖旧黑灰规则：背景 #FFFFFF，文字 #24242B，次级 #666672，大姓名 #FF69A6，头像白色撕纸描边，保留自然减黄肤色。导航为 Zier Min、Work、About、Contact，首页头像约占 60% 桌面宽度，底部自然裁切，不显示肩颈。类目列表仍沿用原黑灰规则，首页下方作品区可用相同白色主题。

本轮动效为桌面优先 2.5D 原型：合拢 / 展开切换约 650ms，工具组浮动约 6s，鼠标视差最大 10px；按钮具有稳定 testid、aria-expanded 和键盘支持。prefers-reduced-motion 禁用循环 / 视差并快速切换。工具 Logo 暂为概念素材，不作为品牌最终资产或独立功能入口。触屏用点击切换，保留窄屏基本可用。

## 设计取向依据

早期黑灰极简、顶部导航、圆角卡片和宽幅留白继续用于类目页；首页以本文件最新覆盖为准。潜在客户按类目扫读作品，Work 区提供五个类目入口。首页新增动效按用户定稿实现，不扩展为复杂三维场景。

### 用户画像适配

## UI 技术栈与组件策略

- Next.js App Router、React、TypeScript；默认 Server Components。必要客户端边界仅用于导航路径识别。
- Tailwind CSS + CSS variables；按 Tailwind v4 方案规划，全局 src/app/globals.css 使用 `@import "tailwindcss"`；开发时核对实际安装版本并锁文件。
- Tailwind 组合语义 HTML；无复杂 Dialog / Dropdown / Select / Tabs，不安装 Radix / shadcn 套件。
- 图表：无。动效库：无。字体：系统字体，无远程下载。
- 禁止独立 CSS 文件堆叠、CSS-in-JS、emoji 功能图标。全局 token 和基础样式集中一处。

## 图标 Iconography

- 全站唯一库与安装包：`lucide-react`，按需导入，文字导航优先。
- 尺寸：`--icon-nav:20px`、`--icon-inline:16px`、`--icon-empty:48px`；统一 strokeWidth=1.5。
- 动作映射：ArrowUpRight 辅助类目跳转，ArrowLeft 辅助回首页，均带文字；不强制加装饰图标。
- 装饰图标 aria-hidden；纯图标按钮必须 aria-label 或 sr-only。本期没有纯图标按钮。

## 媒体与占位图

- 默认 CSS 灰块封面，无图片请求，不用网络样图冒充作品。
- `IMAGE_PROVIDER=none` 为规划策略，不要求添加环境变量或配置界面。本期无 Unsplash、无 UNSPLASH_ACCESS_KEY。
- 类目与作品封面固定 4:3，预留空间防止布局位移；灰块属装饰，aria-hidden，待更新状态用可读文本表达。
- 后续本地素材可放 public/placeholders/ 或作品资源目录；有意义图片需 alt 和明确尺寸，失败回灰块。首版无真实头像、logo、上传能力。

## 数据与演示内容（设计侧约定）

- 数据来源 `FIXTURE`，策略 `FIXTURE_DEMO`；用户明确要求先用占位卡片，不冒充真实项目或已连接服务。
- 默认路径 src/fixtures/portfolio.ts，五类、每类六卡、共三十卡，介绍与名称均为占位。
- 页面显示“内容占位，待更新”，每卡显示“作品待更新”；无需再加重复的示例角标。
- LIVE 未配置态不适用，无 Key、服务连接 CTA。有效类目空集合显示“该类目作品待更新”，保留导航。

## 组件气质与关键界面状态

- SiteHeader：六项文字链接、当前项下划线与 aria-current；普通文档流，不遮挡内容。窄屏换行，不隐藏菜单。
- CategoryCard：整卡真实链接，hover 明度变化、focus-visible 焦点；不改变占位尺寸。
- WorkCard：非交互 article，4:3 封面、标题、描述、待更新标记；无手形光标或点击反馈。
- 默认 / 成功：五类导航、列表六卡；目标页面与高亮表示成功，无 Toast。
- 空态：保留类目标题和导航，显示待更新说明；首页空集合显示“类目待更新”。
- 加载态：静态本地内容无需业务加载；若提供框架 pending 回退，保留标题 / 卡片空间并及时消失。永久内容占位不得持续 shimmer 或 aria-busy。
- 错误态：未知地址显示 404 和回首页链接；配置错误通过校验与测试报告，不伪装空集合。
- 未配置态：无 LIVE 服务，不适用；个人资料未填用明确占位文案表示。
- 过渡 180ms，仅颜色 / 不透明度；prefers-reduced-motion 下取消装饰过渡。提供跳到 main 链接与自然 Tab 顺序。

## 响应式或窗口尺寸

- 小于 640px 一列、640–1023px 两列、1024px 起三列；五个首页入口末行可不足三项。
- 在 320、390、768、1440px 宽度检查全部导航可达、无页面横向溢出。
- 200% 字号与长文自然换行，无固定文字高度截断，标题和卡片不重叠。
- ui-ux-pro-max 仅补工程规范；其检索的订阅表单、浅色底、蓝色强调、远程字体与 PRD 不符，未采用。
