# 分类与作品浏览

## 当前已实现

- 首页 `/` 展示个人介绍占位与五个分类入口。
- `/works/category-1` 至 `/works/category-5` 共用列表模板，当前类目导航高亮。
- 每类六张卡片；明确标记“作品待更新”，不提供详情交互。
- 未知类目与未知路径显示 404，可返回首页。

流程：首页选择类目 → 浏览作品列表 → 顶部切换类目 / 返回首页。类目名称与稳定 URL 分离，内容在集中配置中维护。

## 验证边界

浏览器已验证类目一进入 / 刷新、切换类目五、返回首页；手机类目二与非法类目回退。五条路径全量逐一验收仍见 TODO。真实个人资料、类目名与作品待补；无详情、筛选、后台。
