# 响应式展示与首页交互

## 已实现：Zier Min 连续交互（2026-10-19）

首页保持选定的白底、粉色大姓名、原人物和白色撕纸边。类目页继续黑灰主题，五类作品入口在首页下方。

- 本地两张透明头像加载后，完整头像从底部升起，1250ms 后自动展开工具。取消旧版手动开合按钮。
- 原素材使用 SVG 路径拆为人物、创意腔体、Figma / Codex / Lovart / 即梦四个局部图层。每个工具可单独抬升并显示白色名称标签；键盘聚焦、触屏点击同样可查看标签，尚无跳转业务。
- 鼠标驱动原照片眼部羽化局部层左右最多 4px、上下最多 3px；工具悬停时向上看，移出首屏归中。这是轻微视觉模拟，未制作独立眼球模型或多表情素材。
- 原生滚动驱动姓名缩小淡出、头像上移和 3D CSS 翻面。背面为白色纸片与粉色 LET’S CREATE 字样；作品区在退场后段接入，上滚恢复。不是实际三维头部模型，也没有复刻视频中的张嘴表情。
- 减弱动态时直接显示静态展开态，禁用跟随、抬升、翻面与长滚动区。Work / Selected work / Scroll 锚点进入五类作品，About 进入介绍，Contact 显示“联系方式即将补充”。

## 作品展示骨架

类目页黑底白字、灰色封面、小圆角与宽幅留白。网格小于 640px 一列、640–1023px 两列、1024px 起三列。类目导航允许换行，全部类目保持可访问。

卡片灰块是内容占位而非加载动画。分类卡片可点击，作品卡片仅展示。提供跳到主内容、链接焦点及 reduced-motion 规则。
