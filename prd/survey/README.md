# 设计师协作与 AI 使用调查

## 当前实现

- `/survey` 是仅面向手机布局的 5 部分调查，包含 26 个题目；覆盖设计师基本信息、公司行业与 Agent、项目启动和组内协作、AI 使用、日常跨部门沟通、项目被打回后的修改方案、能力变化和开放经历。Q8–Q10 按需求接收、方向讨论、首稿、组内评审、跨部门对齐、修改和交付七阶段逐项采集角色、AI 占比和对接部门。
- 多选限制、必答验证、前后部分切换、进度、提交中、未连接/失败反馈和感谢页均可操作。问卷不要求姓名，开放经历选填。
- `/survey/analysis` 从服务端读取 Google Sheets 聚合数据，按「基本情况与公司」「项目协作与 AI 使用」「项目修改与能力变化」分组展示 Q1–Q25 的所有选择题；开放回答不进入看板。数据未连接、空数据和请求错误分别呈现。
- 原作品集首页和路由保持不变。

## 数据表

数据表：[Google Sheets 调查数据](https://docs.google.com/spreadsheets/d/1HNU0oSaxioA_FYmHC4lR29ff7twFrDEbgoWr8Sbh0V0/edit)。`回答数据` 保存提交时间与 Q1–Q26；`分析概览` 提供自动计数公式。网站分析图表由 Apps Script 按选项聚合，不读取开放回答原文。

## 使用边界

本地交互和未配置状态已通过验收。真实收集需要按 [部署步骤](../../google-apps-script/DEPLOY.md) 将 Apps Script Web App 部署为服务端数据桥接，并在 `.env.local` 配置 URL 与共享令牌；该外部部署尚未执行。部署后重启 Next.js 并用一份测试问卷验证实际写入与统计更新。
